# Location, From→To routing, and navigation voice

## Your current location
- Map auto-requests GPS (browser permission).
- Blue location control (top-right) also tracks you.
- When GPS is available, routes default **from your position**.

## From → To
- Tap **Directions** on the map.
- **From:** My current location *or* a listed place.
- **To:** Destination place.
- **Calculate route** runs risk-aware alternatives (Phase 5).

## Voice + guidance
- Route ready: speaks from/to, time, distance.
- If path crosses a reported blockage: speaks which road.
- **Start navigation:** speaks each turn + distance for that step (m/km).
- Mute on the navigation screen stops speech.

## Still limited (honest)
- Turn simulation advances on a timer, not live GPS along the polyline yet.
- True “in 200 m turn left” while driving needs continuous position-on-route matching (next upgrade).
